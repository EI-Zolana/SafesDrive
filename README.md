 **Resumo**

Pretende-se desenvolver um repositório de sistema distribuído on-line semelhante ao google drive,com o objetivo é que o usuário da nossa drive consiga fazer o upload/download de ficheiros, para a sua drive pessoal e que tenha a confiança de que não perderá nada, pois terá tudo guardado em vários servidores. Para tal feito teremos implementação de um sistema distribuído tolerante a faltas, no qual os diferentes componentes do sistema são executados de forma distribuída cooperando através de uma rede de comunicação.

O utilizador fará o login, e quando enviar ou baixar o seu ficheiro o sistema distribuirá os dados nos diferentes servidores. Se desligarmos um dos servidores, o utilizador poderá conseguir descarregar os ficheiros.
